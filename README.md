# DA-07 — Customer Churn Analytics

This repository is being developed as a portfolio-grade customer churn analytics case study focused on churn drivers, retention patterns, customer segmentation, risk analysis, and actionable business insights.

## Data strategy

DA-07 will use a real/public dataset with verifiable provenance and documented licensing. Large raw files will not be committed to Git. Instead, the repository will document the source, schema, acquisition steps, cleaning logic, analytical assumptions, and limitations.

## Planned scope

- Public/externally sourced churn dataset
- Data provenance and data dictionary
- Churn rate and retention KPIs
- Segment-level churn analysis
- Contract, tenure, service, and payment-pattern analysis where supported
- Customer risk profiling and descriptive retention signals
- Data quality and cleaning checks
- Reproducible Python analytics
- Tests and GitHub Actions CI

> Full development will happen on a dedicated branch before final review and merge.
